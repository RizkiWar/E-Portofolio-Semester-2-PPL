# E-Portfolio 1 — Praktik Mengajar Mandiri

Website Next.js siap dikembangkan untuk portofolio profesional guru.

## Menjalankan
1. Pastikan Node.js 18+ terpasang.
2. Buka folder project di terminal.
3. Jalankan `npm install`.
4. Jalankan `npm run dev`.
5. Buka `http://localhost:3000`.

## Build production
`npm run build`
`npm start`

## Kustomisasi
Edit `app/page.js` untuk mengganti identitas, isi analisis, tautan video, dan dokumentasi. Edit `app/globals.css` untuk mengubah warna dan tampilan.

Folder `public/` disediakan untuk foto, logo, dan dokumen pendukung yang ingin ditampilkan.
